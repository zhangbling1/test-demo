# 方向一 · 《赵云与阿斗》—— 西游画风

题目：《赵云与阿斗》做成西游风格。这一版**人物和玩法全照原作**（赵云、阿斗、刀枪骑弓、凑名字召武将、花馒头征兵、阿斗三条命、1V1 上下对称），只把**画面**换成西游的样子。

## 一句话

三国的人，西游的画：Q版圆脸小人，祥云铺路，天宫的金瓦红柱，平涂加粗描边。

## 西游风格落在哪

| 地方 | 做法 |
|---|---|
| 人物 | Q版圆脸：豆豆眼、腮红、平涂粗描边，不画写实的光影。赵云银盔红缨、刘海；关羽绿巾长须眯眯眼；张飞一圈刺刺胡子；黄忠金盔白须；刘备大耳朵金冠 |
| 阵营 | 我方是蜀，守阿斗；对手是曹营的夏侯惇（独眼罩、蓝盔、「魏」字旗），守曹冲。打我方的是曹兵（蓝衣），打对手的是蜀兵（绿衣） |
| 路 | 敌人走的路是一条**云路**（一串圆先描边再填白，边缘自然成云朵的鼓包） |
| 建筑 | 主页背后是天宫式门楼，牌匾写「长坂坡」；商店是金瓦红柱的铺面「云中集市」 |
| 阿斗的命 | 三颗**仙桃** |
| 兵牌 | 刀红、枪蓝、骑绿、弓橙，金边令牌，白字黑边；等级是牌底的金点 |
| 按钮 | 金色令牌；底部导航是一排金瓦屋檐 |
| 色 | 朱红、金、群青、石绿、天青，上美影《大闹天宫》那种平涂 |

## 原作的东西都在

- 征兵花**馒头**，一次比一次贵；抽到的字进**字匣**（5 格）
- 字拖上空格才上阵；**同字同级**拖到一起合成，最高 5 级
- 「赵」「云」拖到一起召出**赵云**；张飞、黄忠同理（「将缘」显示凑字进度）
- 「铲」开垦锁着的格子；兵可以拖到「卖」上换馒头
- 阿斗被摸到就掉一颗桃，同时**补给馒头**（原作的"卖血经济"）
- 对手的曹冲先没命你就赢；军衔星级、当天有效的道具都保留

## 页面

1. **主页**：赵云抱着阿斗站在云上，身后门楼匾写「长坂坡」；主按钮「开战」。
2. **匹配**：「点将台」，罗盘转着找对手；下面是出战阵容。
3. **匹配成功**：上蓝（魏）下红（蜀），祥云一线隔开，夏侯惇对赵云，中间金牌「战」。
4. **战斗**：上对手下自己；字匣、征兵、两个技能（护主、七进七出）。
5. **结算 · 胜**：「大胜」，赵云喊一嗓子，阿斗举着馒头蹦起来。
6. **结算 · 败**：「惜败」，阿斗哭了，卡片说下次怎么守。
7. **商店**：「云中集市」，掌柜是刘备的财主糜竺；今日特供当天有效。

## 演示（demo.html）

- 主页「开战」→ 匹配 → 匹配成功倒数 → 战斗 → 胜 / 败 → 再战或回主页
- 战斗能真玩：征兵、拖拽上阵、合成、凑赵云、铲子开格、卖兵、护主、七进七出（要先召出赵云）
- 结算页显示这一局的真实数据（第几波、合成次数、击退曹兵数、MVP）
- 商店能买，买的东西下一局生效：仙桃（阿斗 4 条命）、青釭剑（刀兵攻击 +20%）、的卢马（骑兵更快）、铲子（开局多一格）、招贤令（更容易抽到武将字）
